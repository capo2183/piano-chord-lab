# Piano Chord Lab 🎹

互動式鋼琴和弦學習網站。隨機出題 → 自己在鋼琴上找音 → 點一下揭曉 → 對照五線譜、琴鍵、指法與「琴鍵間隔公式」→ 下一題。

- 純靜態網站（HTML + CSS + JavaScript），不需要後端、帳號、資料庫或任何付費服務
- 直接開啟 `index.html` 即可使用（包含 `file://`），也可部署到 GitHub Pages
- 介面為繁體中文，針對 Samsung Galaxy 等手機與桌面瀏覽器設計

預期網址：<https://capo2183.github.io/piano-chord-lab/>

## 功能

| 功能 | 說明 |
| --- | --- |
| 隨機和弦測驗 | 題目只顯示和弦代號，點題目卡片或「顯示答案」才揭曉；不會連續兩題相同 |
| 完整答案 | 組成音（含級數）、五線譜、鋼琴鍵盤、建議指法、琴鍵間隔公式、中文名稱 |
| 琴鍵間隔記憶法 | 相鄰兩個要彈的琴鍵之間「隔了幾個琴鍵」（黑白鍵都算），例如 Cmaj7 = **3－2－3**，同時列出傳統半音數對照 |
| 五線譜 | SVG 動態繪製：高音譜號（右手）＋低音譜號（左手／斜線低音）、升降與重升重降記號、加線、二度錯位 |
| 鋼琴鍵盤 | 依和弦自動選擇音域；右手（青色）、左手（琥珀色）分色；琴鍵上標示音名與手指編號；左右手距離太遠時自動分段，手機不需橫向捲動 |
| 指法 | 依琴鍵實際分布計算（例如 C6 的 G、A 相鄰會改用 4-5 指）；跨距超過八度的和弦自動建議左右手分配 |
| 練習模式 | A 指定和弦、B 基礎、C 七和弦、D 進階（延伸／斜線和弦）、E 全部隨機 |
| 練習紀錄 | 「我答對了／我還不熟」、題數與答對率、localStorage 保存；不熟的和弦會優先複習；localStorage 無法使用時自動改用記憶體 |
| 播放和弦 | Web Audio API 合成近似鋼琴音色，只在按下「播放」或「分解」時發聲 |
| 逐步練習 | 可分別隱藏音名、間隔公式、指法 |
| 快速鍵（桌面） | 空白鍵＝顯示答案／下一題、1＝我還不熟、2＝我答對了、P＝播放 |

### 支援的和弦

- 根音：C、C♯、D♭、D、D♯、E♭、E、F、F♯、G♭、G、G♯、A♭、A、A♯、B♭、B（12 個半音、含升降寫法）
- 基本：Major、m、dim、aug、sus2、sus4
- 七和弦：7、maj7、m7、m(maj7)、m7♭5、dim7、7sus4
- 延伸：6、m6、add9、m(add9)、9、maj9、m9、11、m11、13
- 斜線和弦：例如 C♯m7♭5/F♯、C/E、Am7/D
- 模式 A 預設題目：`Emaj7`、`D#m7`、`G#m7`、`C#m7(9)`、`C#m7(-5)/F#`

所有和弦音都由「根音＋音程公式（字母級數＋半音數）」計算，不是硬編碼，也不是用 MIDI 半音反推音名，
所以能得到正確的樂理拼寫，例如 C♯ 大三和弦的三音是 **E♯**、G♯aug 的五音是 **D♯♯**、Cdim7 的七音是 **B♭♭**。
出題時若某個根音會產生重升重降、而等音寫法較簡單，會自動改用等音寫法（例如 D♯maj7 → E♭maj7）；D♯m7 這類常用寫法則保留。

> 屬十三和弦依爵士／流行慣例省略 11 度音（C13 = C、E、G、B♭、D、A）。

## 使用方式

1. 看到和弦代號（例如 `Emaj7`）後，先自己在鋼琴上找出組成音。
2. 點一下題目卡片（或下方「顯示答案」）。
3. 對照鍵盤上的手指編號、間隔公式（例如 `3－2－3`）與五線譜。
4. 按「我答對了」或「我還不熟」記錄並進入下一題；或按「下一題」略過不記錄。
5. 「顯示設定與練習紀錄」可以隱藏音名／間隔／指法，查看不熟的和弦與最近作答，或清除紀錄。

## 專案結構

```
index.html            入口（GitHub Pages 根目錄）
css/style.css         深色主題、行動裝置優先的樣式
js/theory.js          樂理：音名拼寫、音程、和弦公式、代號解析、琴鍵間隔
js/voicing.js         八度配置、左右手分配、斜線低音
js/fingering.js       指法成本模型（依琴鍵分布挑選指法）
js/staff.js           五線譜 SVG 繪製（加線、臨時記號分欄、二度錯位）
js/keyboard.js        鋼琴鍵盤 SVG 繪製（音域、分段、標示）
js/audio.js           Web Audio 鋼琴近似音色
js/storage.js         練習紀錄（localStorage／記憶體備援）
js/quiz.js            練習模式與出題（避免重複、優先複習）
js/app.js             介面控制
tests/*.test.js       單元測試（Node 內建 test runner，無需安裝套件）
tests/e2e/            瀏覽器端對端測試（Playwright）
```

所有 JS 皆為一般 `<script>`（非 ES module），因此直接雙擊 `index.html` 以 `file://` 開啟也能運作；
同一份檔案也可在 Node.js 中 `require()` 進行測試。

## 本機執行

```bash
# 直接用瀏覽器開啟 index.html，或啟動簡易伺服器：
python3 -m http.server 8000
# 然後開啟 http://localhost:8000/
```

## 測試

```bash
npm test            # 單元測試（Node 18+，不需 npm install）
npm run test:e2e    # 瀏覽器測試（需要 playwright 與 Chromium）
```

單元測試涵蓋：所有和弦類型 × 17 種根音寫法的組成音與間隔、五個指定題目、升降與等音拼寫、
代號別名解析、斜線和弦左右手分配、五線譜與鍵盤音高一致、指法合理性、鍵盤寬度、出題不重複與模式範圍、
不熟和弦優先複習、localStorage 正常／停用／資料毀損。

瀏覽器測試涵蓋：`file://` 與 GitHub Pages 子路徑載入、揭曉前不洩漏答案、五線譜與鍵盤一致、
模式切換與連續出題、紀錄保存、localStorage 被封鎖、顯示設定、播放、320～412px 手機與桌面排版、無障礙標籤、快速鍵。

## 部署到 GitHub Pages

網站是純靜態檔案，`index.html` 位於儲存庫根目錄，並附上 `.nojekyll`，不需要任何建置步驟。

1. 進入 GitHub 儲存庫 **capo2183/piano-chord-lab** → **Settings** → **Pages**。
2. **Build and deployment → Source** 選擇 **Deploy from a branch**。
3. **Branch** 選擇存放網站的分支（通常為 `main`）與 **/ (root)**，按 **Save**。
4. 約 1～2 分鐘後，網站會出現在 <https://capo2183.github.io/piano-chord-lab/>。

之後只要推送到該分支，GitHub Pages 就會自動更新。
